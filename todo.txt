## 1. Script skeleton & globals
- [ ] Shebang, set -euo pipefail
- [ ] Source /etc/apt-oob.conf if it exists (before deriving paths)
- [ ] OOB_BASE="/usr/local/apt-oob" (overridable via apt-oob.conf)
- [ ] LOG_FILE="/var/log/apt-oob.log" (overridable via apt-oob.conf)
- [ ] Derived paths: OOB_CONF, OOB_CHECKVER, OOB_DLOAD, OOB_CHECKSUM, OOB_KEYS, OOB_LIVE, OOB_STATE
- [ ] APT_HOOK="/etc/apt/apt.conf.d/99-apt-oob"
- [ ] Root check — exit 1 if EUID != 0

## 2. Flag parsing
- [ ] Parse -f/--force, -n/--dry-run, -v/--verbose, -q/--quiet, -h/--help
- [ ] Parse subcommand: install, check, remove, list, status, init, deinit
- [ ] Parse optional [name] argument for install, check, status, remove

## 3. Output functions
- [ ] info()    — cyan
- [ ] warn()    — yellow
- [ ] error()   — red
- [ ] success() — green
- [ ] highlight() — magenta
- [ ] bold()    — white
- [ ] All write to log in syslog format: "Mon DD HH:MM:SS oob[PID]: [LEVEL] message"
- [ ] All write to terminal unless -q
- [ ] Log file append, create if missing

## 4. Helper: conf.d loader
- [ ] load_conf() — source a conf.d file, validate required fields (NAME, DOWNLOAD, VERSION_CHECK, INSTALL_DIR, SYMLINKS, SYMLINK_DIR)
- [ ] Warn if CHECKSUM is unset (not "none", just missing)
- [ ] Warn if GPG_KEY is unset (log only, print with -v)
- [ ] Reset conf variables between packages to avoid bleed

## 5. Helper: template variable substitution
- [ ] expand_template() — given a version string and a URL, replace {VERSION}, {MAJOR}, {MINOR}, {REVISION}
- [ ] Handle 2-component versions (e.g. 148.0) — {REVISION} becomes empty string

## 6. Helper: resolve download URL
- [ ] If DOWNLOAD starts with https://, expand template variables
- [ ] Otherwise treat as script name under OOB_DLOAD, run with version as $1, capture URL from stdout

## 7. Helper: archive extraction
- [ ] extract_archive() — detect format from filename extension
- [ ] Support: .tar.gz/.tgz, .tar.xz/.txz, .tar.bz2/.tbz2, .tar, .zip
- [ ] Extract into target INSTALL_DIR

## 8. Helper: checksum verification
- [ ] run_checksum() — run script from OOB_CHECKSUM with version as $1
- [ ] Parse "algo:hash" output
- [ ] Compute matching hash (sha256sum or sha512sum) on downloaded file
- [ ] Compare, return 0/1

## 9. Helper: GPG signature verification
- [ ] run_gpg_verify() — if GPG_KEY is set, import key from OOB_KEYS into temp keyring
- [ ] Download detached signature from GPG_SIG_URL (expand template variables)
- [ ] Verify signature against downloaded archive
- [ ] Error if GPG_KEY set but key file missing or GPG_SIG_URL not defined
- [ ] Skip silently if GPG_KEY not set (log warning, print only with -v)

## 10. Helper: symlink management
- [ ] create_symlinks() — iterate SYMLINKS, create links in SYMLINK_DIR pointing to INSTALL_DIR/relative_path
- [ ] remove_symlinks() — read state file SYMLINKS, remove each link

## 11. Helper: state file management
- [ ] write_state() — write to temp file then mv (atomic)
- [ ] Fields: INSTALLED_VERSION, INSTALL_DATE (ISO 8601), INSTALL_PATH, SYMLINKS (resolved absolute paths)
- [ ] read_state() — source state file, return installed version

## 12. Command: install
- [ ] If name given, process single conf.d entry matching NAME
- [ ] If no name, iterate all conf.d/* in lexical order
- [ ] Per package: load conf, run version check, compare to state, skip if current (unless --force)
- [ ] Download to mktemp -d, run checksum, run gpg verify, remove old INSTALL_DIR, extract, create symlinks, write state
- [ ] Cleanup temp dir in trap on both success and failure
- [ ] --dry-run: show steps without executing
- [ ] On per-package failure: log error, continue to next package

## 13. Command: check
- [ ] Same iteration as install but only run version check
- [ ] Print "name: installed=X available=Y" or "(up to date)" or "not installed"

## 14. Command: remove
- [ ] Require name argument
- [ ] Prompt y/n unless --force
- [ ] Remove INSTALL_DIR contents, symlinks (from state file), state file
- [ ] --dry-run: show what would be removed

## 15. Command: list
- [ ] Iterate conf.d/*, load NAME from each
- [ ] If state file exists, show installed version
- [ ] If no state file, show "configured, not installed"

## 16. Command: status
- [ ] Require name argument
- [ ] Load and display state file contents
- [ ] Run version check, show if update available

## 17. Command: init
- [ ] Create oob directory structure under /usr/local/apt-oob
- [ ] Write default /etc/apt-oob.conf with commented-out values if it doesn't exist
- [ ] Check if APT_HOOK exists — warn and prompt to overwrite
- [ ] Write the DPkg::Post-Invoke line to APT_HOOK

## 18. Command: deinit
- [ ] Remove APT_HOOK file if it exists
- [ ] Warn if it doesn't exist

## 19. Unit tests (unit-tests/)
- [ ] helpers.sh — shared setup/teardown, temp OOB_BASE, source oob functions
- [ ] run.sh — test runner, executes all test files, reports pass/fail summary
- [ ] expand_template.sh — 3-component, 2-component, empty revision
- [ ] conf_loader.sh — valid conf, missing fields, omitted CHECKSUM/GPG_KEY warnings
- [ ] state.sh — write_state atomic mv, read_state, missing state file
- [ ] symlinks.sh — create_symlinks, remove_symlinks, resolved paths
- [ ] extract_archive.sh — tar.gz, tar.xz, tar.bz2, zip, unsupported format
- [ ] checksum.sh — sha256 match, sha512 match, mismatch, bad algo, script not found
- [ ] checksig.sh — GPG_KEY missing file, missing GPG_SIG_URL, empty GPG_KEY skips
- [ ] init.sh — creates directory structure, writes apt hook, warns on existing
- [ ] deinit.sh — removes hook, warns if missing
- [ ] install.sh — new install, skip current version, --force reinstall, --dry-run
- [ ] check.sh — up to date, update available, not installed
- [ ] remove.sh — removes files/symlinks/state, --force skips prompt, --dry-run
- [ ] list.sh — installed packages, configured but not installed
- [ ] status.sh — shows state, checks for update
